# DompetKu v2.0.0

Data keuangan terhubung antara Android dan web melalui akun Google.

## Pembaruan

- Menambahkan login Google pada Android.
- Menyinkronkan transaksi, dompet, budget, tagihan, dan target tabungan antarperangkat.
- Menambahkan pemindahan data perangkat lama dengan backup dan konfirmasi.
- Menambahkan pengingat tagihan native Android.
- Mempertahankan perlindungan PIN ketika aplikasi dibuka melalui notifikasi.

## Catatan pembaruan

- Cadangkan data sebelum memperbarui aplikasi.
- Gunakan akun Google yang sama pada Android dan web.
- Pengingat Android mengikuti jadwal terakhir yang tersinkron.
- Buka aplikasi untuk memperbarui perubahan jadwal dari perangkat lain.
